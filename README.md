# 🍔 CampusBite – Smart Campus Food Ordering System

CampusBite is a web-based campus food ordering application designed to make food ordering easier, faster, and more convenient for students.

The application allows students to browse food items, place orders, and track their order status in real time. It also helps manage orders efficiently through a simple and user-friendly interface.

## ✨ Features

- **User-Friendly Interface:** Simple and easy-to-use design.
- **Food Ordering:** Browse available food items and place orders.
- **Order Management:** Manage and view customer orders.
- **Live Order Tracking:** Track order status through different stages:
  - Placed
  - Preparing
  - Ready
- **Database Integration:** Stores application data using Supabase.
- **Real-Time Updates:** Keeps order information updated.

## 🗄️ Database

CampusBite uses **Supabase**, an open-source backend platform built around PostgreSQL.

It is used for:
- Storing food and order information.
- Managing order records.
- Updating order status.
- Connecting the frontend application with the database.

## 📌 Order Workflow

1. Student opens the CampusBite application.
2. Student browses the available food items.
3. Student places an order.
4. Order status changes to **Placed**.
5. The order is processed and changes to **Preparing**.
6. Once completed, the status changes to **Ready**.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the required dependencies:

   ```bash
   npm install
   ```

5. Configure the Supabase project credentials in the environment configuration file.
6. Start the development server:

   ```bash
   npm run dev
   ```

7. Open the local URL displayed in the terminal.
